# AI-Based Skill Gap Analyzer

## 📌 Project Overview

AI-Based Skill Gap Analyzer is a Python and Streamlit based application that helps job seekers identify the skills they already have and the skills they need to learn for a selected job role.

The application compares the candidate's skills with the required skills for the selected job role and calculates the skill match percentage.

## ✨ Features

- Select a target job role
- Enter candidate skills
- Identify matching skills
- Identify missing skills
- Calculate skill match percentage
- Display skill gap recommendations
- Visualize results using a bar chart

## 🛠️ Technologies Used

- Python
- Pandas
- Excel
- Streamlit
- Matplotlib

## 📂 Dataset

The project uses an Excel dataset named `job_skills.xlsx`.

It contains:
- Job roles
- Required skills for each role
